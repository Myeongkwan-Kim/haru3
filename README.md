# 하루 세 아이

유치원 교사가 수업 중 짬에 10초로 남기는 아이 관찰 기록 도구.
2주 파일럿용 프로토타입입니다.

## 설계 전제

- **전수 기록을 하지 않습니다.** 하루에 눈에 띈 아이 2~3명만 남기고,
  기록되지 않은 아이는 결측이 아니라 "평범했다"로 취급합니다.
- **관찰이 일어나는 시간과 기록하는 시간이 다릅니다.** 쉬는 시간에 사건이
  벌어지고 수업 시간에 짬이 나므로, 입력은 언제나 30분~1시간 뒤의 회상입니다.
  그래서 시간대(슬롯) 단위로 기록합니다.
- **사실과 해석을 분리해서 받습니다.** 관찰 태그(무슨 일이 있었나)와
  감정 축(선생님이 본 아이 상태)이 별도 필드입니다. 한 필드에 뭉치면
  나중에 어떤 대시보드로도 편향을 되돌릴 수 없습니다.
- **감정 축은 빨강–초록이 아닙니다.** 파랑(위축)–회색(평소)–앰버(활발)로,
  좋고 나쁨의 가치판단이 덜 실리게 했습니다.
- **첫 화면의 주인공은 점수가 아니라 공백입니다.** 4일 넘게 기록이 없는
  아이를 상단에 올려, 조용해서 눈에 안 띄는 아이가 드러나게 합니다.

## 파일

| 경로 | 용도 |
|---|---|
| `index.html` | 원본. Artifact 본문 규격이라 `<!doctype>`·`<head>`·`<body>`가 없습니다 |
| `build.sh` | 원본을 완전한 HTML 문서로 감싸 `dist/`를 만듭니다 |
| `dist/index.html` | 자체 호스팅용 완전판 (PWA 메타 포함) |
| `dist/manifest.json`, `dist/icon.svg` | 홈 화면 추가용 |

편집은 `index.html`에만 하고, `./build.sh`로 `dist/`를 다시 만듭니다.

## 자체 호스팅

정적 파일 3개뿐이라 아무 웹서버에나 `dist/` 내용을 올리면 됩니다.
**HTTPS여야 홈 화면 추가와 standalone 표시가 정상 동작합니다.**

로컬 확인:

    python3 -m http.server 8931 --bind 127.0.0.1 --directory dist

## 데이터

브라우저 `localStorage`(키 `haru3.v1`)에만 저장됩니다. 서버가 없습니다.

- 브라우저 데이터를 지우면 기록도 사라집니다.
- 데이터 탭에서 CSV/JSON으로 복사해 며칠에 한 번 빼두세요.
- 2주 파일럿이 끝나면 CSV를 DB로 옮겨 대시보드를 만드는 것이 다음 단계입니다.

## 2주 파일럿에서 확인할 것

1. 하루에 실제로 몇 명을 기록하는가 (0명인 날이 며칠인가)
2. 어느 시간대에 기록하는가
3. 이모지·태그만으로 충분한가, 결국 한 줄 메모를 쓰게 되는가
4. "놓치고 있는 아이"를 보고 실제로 그 아이를 기록하러 가는가

이 네 가지 답이 스키마와 다음 버전의 형태를 결정합니다.
