# 0002. 사실과 해석을 다른 필드로 받는다

- 상태: 채택
- 날짜: 2026-09-09

## 맥락

교사가 남기는 기록은 최종적으로 학부모에게 전달될 수 있습니다. 교사의 사견이
한쪽으로 치우치면 학부모가 반발하는 일이 실제로 생깁니다.

한 필드에 "친구를 밀었다 😞"처럼 뭉쳐서 받으면, 나중에 어떤 필터를 걸어도
편향을 되돌릴 수 없습니다. 사실과 판단이 이미 한 덩어리이기 때문입니다.

## 결정

입력 단계에서 두 필드로 나눕니다.

- **관찰 태그** — 무슨 일이 있었나 (사실)
- **상태 축** — 선생님이 본 아이 상태 (해석)

화면에도 "사실만" / "해석"이라는 라벨을 붙여 구분을 드러냅니다.

## 근거

같은 "친구를 밀었다"도 잠을 못 잔 날인지 아닌지에 따라 의미가 다릅니다. 분리해
두면 나중에 교사 본인이 **"내가 이 아이한테 최근 부정적인 해석을 유독 많이
달았구나"** 를 볼 수 있고, 이것이 자기교정 장치가 됩니다.

## 결과

- 입력 단계가 한 단계 늘어납니다. 대신 둘 다 선택 사항이라 하나만 채워도
  저장됩니다.
- 학부모에게 내보내는 기능을 나중에 만들 때, 사실 필드만 내보내고 해석 필드는
  교사 내부용으로 남기는 선택지가 열려 있습니다.
