# 0003. 상태 축을 빨강-초록이 아닌 파랑-회색-앰버로 한다

- 상태: 채택
- 날짜: 2026-09-09

## 맥락

5단계 상태 축에 색을 입혀야 했습니다. 가장 흔한 선택은 빨강(나쁨)에서
초록(좋음)으로 가는 신호등 스케일입니다.

## 결정

**파랑(위축) - 회색(평소) - 앰버(활발)** 의 발산형 스케일을 씁니다. 라벨도
좋음/나쁨이 아니라 상태 서술입니다: 위축 / 시무룩 / 평소 / 밝음 / 활발.

## 근거

신호등 색은 값 판단을 강하게 실어 나릅니다. "이 아이는 빨강"이라는 인상이
데이터에 박히면, 나중에 학부모에게 내보낼 때 그 낙인이 따라갑니다. 아이가
위축된 것은 고쳐야 할 결함이 아니라 그날의 상태입니다.

파랑-앰버는 방향은 구분되면서 우열이 덜 실립니다. 발산형 스케일의 정석대로
중간은 무채색입니다.

색만으로 구분하지 않도록 다섯 칸 모두에 이모지와 한글 라벨을 직접 붙였습니다.
색상 검증기에서 인접한 두 칸의 색 차이가 권장치에 못 미치는데, 위치와 라벨이
보조 인코딩 역할을 하므로 허용 범위로 판단했습니다.

## 결과

- 저장되는 값은 -2 ~ +2의 정수이므로, 나중에 색만 바꾸는 것은 언제든 가능합니다.
- 다만 이 축을 "좋고 나쁨"으로 해석하는 통계를 나중에 붙이면 이 결정이 무의미해
  집니다. 대시보드를 만들 때 이 문서를 다시 읽어야 합니다.
