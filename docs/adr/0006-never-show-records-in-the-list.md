# 0006. 아이 목록 화면에 기록 내용을 싣지 않는다

- 상태: 채택
- 날짜: 2026-09-10

## 맥락

기록 화면의 아이 카드에는 마지막 기록의 요약이 함께 떴습니다.
`서아 — 활발 · 참여 어려움 +1` 같은 식입니다. 교사가 한눈에 파악하기
좋으라고 넣은 것이었습니다.

그런데 이 앱은 **아이들 앞에서, 아이들 사이에서** 열립니다. 영어유치원이면
글을 읽는 아이도 있습니다. 옆에서 화면을 보면 다른 아이에 대한 교사의 관찰과
해석이 그대로 노출됩니다.

## 결정

목록 화면(기록 탭)의 카드에는 **이름과 기록 여부만** 표시합니다.

- 오늘 기록이 있으면 `오늘 N건`
- 없으면 `N일 전` 또는 `아직 기록 없음`
- 기록 본문, 상태 이모지, 상태 색 막대는 싣지 않습니다

기록 내용은 시트를 열었을 때(그 아이 하나만)와 상담 탭에서만 보입니다. 상담
탭은 통화를 준비하거나 통화하는 시점에 보는 화면이라 아이들 앞이 아닙니다.

## 결과

- 교사가 목록만 보고 "이 아이에게 뭘 적었더라"를 알 수 없습니다. 한 번 더
  눌러야 합니다. 이것은 감수하는 비용입니다.
- 같은 이유로 음성 입력을 넣지 않습니다(`docs/adr/0005`).
- 앞으로 목록·요약 화면을 추가할 때마다 이 문서를 먼저 읽어야 합니다.
  "한눈에 보이면 좋겠다"는 요구는 이 제약과 늘 충돌합니다.
